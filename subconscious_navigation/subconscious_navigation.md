# 意識潛航
## 題目意思
在未來的賽博龐克世界中，神經漫遊者需要透過「意識潛航」進入深層虛擬網路。潛航過程由一系列的時間區塊組成，每個時間區塊可以選擇「深度下潛」或是「上浮緩衝」。
然而，人類的神經突觸無法承受過長時間的連續高壓連結。如果連續處於「深度下潛」狀態超過 n 個單位時間，潛航者的意識就會過載並迷失在數位虛空中。
現在有一趟總時長為 m 個單位時間的潛航任務，請你撰寫一支程式，給定 n 與 m 的數值，計算在遵守安全機制（即任何時刻都不會出現連續超過 n 個單位時間的「深度下潛」狀態）的前提下，共有多少種不同的潛航狀態排程方式？
## 輸入格式
輸入包含兩個整數 n 與 m，兩個數字之間以一個空白字元分開。
## 輸出格式
對於每一筆輸入，請輸出一個整數，代表所有合法的排程方式總數。
## 範圍限制
1 <= n <= 15
1 <= m <= 90
（答案保證不會超過 2的64次方減1，因此不需要考慮大數運算的情況）
# 意識潛航
## 題目想法
因為這題有「連續下潛長度」的限制（最多不能超過 n 個單位時間），所以不能單純只用一維陣列來記錄前 i 個的排列總數。必須將狀態拆分成兩種，清楚區分當下這個時間點是否處於下潛狀態，才能準確控管連續發生的次數，進而嘗試所有合法的情況。
## 解題過程
為了區分狀態，我設定了一個二維的動態規劃陣列 dp[i][j]：
 * j = 0 代表第 i 個時間點「不上浮緩衝（不亮/不下潛）」。
 * j = 1 代表第 i 個時間點「深度下潛（亮/下潛）」。
因此：
 * dp[i][0LL] 代表：如果第 i 個時間點不下潛，前 i 個時間點的合法排列方法總數。
 * dp[i][1LL] 代表：如果第 i 個時間點下潛，前 i 個時間點的合法排列方法總數。
## 解題方法思考
狀態轉移方程式的邏輯如下：
 * 當第 i 個時間點選擇「不下潛」時：
   dp[i][0LL]=dp[i-1LL][1LL]+dp[i-1LL][0LL];
   這包含了第 i-1 個時間點的所有可能情況（無論是下潛還是不下潛），因為只要當下停頓了，連續下潛的計數就會被中斷並重置，所以可以直接將前一次的兩種狀態總和加起來。
 * 當第 i 個時間點選擇「下潛」時：
for (int k=1LL;k<=n&&i-k>=0LL;k++)
{
    dp[i][1LL]+=dp[i-k][0LL];
}

因為不能連續下潛超過 n 個時間點，所以利用迴圈變數 k (範圍從 1 到 n) 來枚舉「目前這一段連續下潛的長度」。如果這一段連續下潛了 k 次，代表第 i-k 個時間點必須是「不下潛」的狀態 (dp[i-k][0LL])，以此來確保每一次的連續下潛都能被合法追溯，不會超出 n 的限制。
## 複雜度分析
 * 時間複雜度：O(n * m)。
外層迴圈執行 m 次，內層迴圈最多執行 n 次進行狀態轉移。
 * 空間複雜度：O(m)。
建立了一個大小為 (m+1) * 2 的二維陣列來儲存 DP 狀態。
## 學習心得
在處理帶有「連續次數限制」的動態規劃問題時，將狀態依照「當下是否執行該動作」進行維度拆分是非常有效的技巧。同時，遇到連續狀態的計算，可以直接往回看 k 步，尋找上一個「中斷點（不上潛的狀態）」，這樣就能完美避開在同一個狀態內混淆連續次數的問題。
