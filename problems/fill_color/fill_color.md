# 填色
## 題目意思
給定一個大小為 N*M 的網格，每個格子需要填入編號為 1、2 或 3 的三種顏色之一。
為了美觀，規定任意相鄰的格子（上下左右相鄰）嚴禁使用同種顏色。
現在已知第 K 行的顏色配置已經被固定且無法修改。
請計算在滿足上述相鄰不同色限制下，整個 N*M 網格總共有多少種合法的著色方案。
由於答案可能很大，請輸出答案對 1000000 取餘數的結果。
若不存在任何滿足條件的方案，請輸出 0。
## 輸入格式
第一行包含兩個整數 N 和 M，分別代表網格的行數與列數。
第二行包含一個整數 K，代表被固定顏色的行編號。
第三行包含 M 個整數，表示第 K 行各個格子的顏色方案。
## 輸出格式
輸出一個整數，代表在第 K 行固定情況下的合法著色方案總數（對 1000000 取餘數）。
## 範圍限制
1 <= N <= 10^4
1 <= M <= 5

# 填色
## 題目想法
這是一道典型的狀態壓縮動態規劃（State Compression DP）題目。
因為題目給定的列寬 M <= 5，範圍非常小，每一行的合法狀態數最多大約只有 48 種。
因此，我們可以先用 DFS 暴力枚舉出所有長度為 $M$ 且水平相鄰格子不同色的合法狀態。
接著透過雙層迴圈預先處理出任意兩種狀態之間是否能夠上下相鄰，並建立相容性矩陣。
動態規劃的狀態可以設計為 dp[i][s]，代表考慮前 i 行且第 i 行選擇第 s 種合法狀態時的合法方案總數。
特別的是，當做到第 K 行時，必須強制對齊題目指定的固定狀態。
## 解題過程
合法狀態枚舉：撰寫遞迴函式（DFS），生成所有長度為 M 且任意相鄰元素不同的組合，並存入陣列 lines 中。
同時檢查題目給定的第 K 行狀態 k_line 在所有合法狀態中的索引位置 pos。如果連 k_line 本身都不合法，直接輸出 0。
狀態相容性預處理：定義 vers 函式，檢查兩個狀態在對應列的相同位置上是否顏色相同（上下相鄰不能同色）。
利用雙層迴圈計算出任意兩個狀態 i 與 j 是否可以上下相鄰，並存入 ship 矩陣中。
動態規劃轉移：宣告 dp[n+1][t] 陣列，其中 $t$ 為合法狀態總數。
初始化時，若 K = 1，則將 dp[1][pos] 設為 1，其餘為 0；若 K > 1，則第一行的所有合法狀態皆可選，設為 1。
從第 2 行遞推到第 N 行：當行數等於 K 時，只能由上一行轉移到固定的狀態 pos；若不等於 K，則透過雙層迴圈累加所有與上一行狀態相容的轉移方案數（記得每次加總都要取模 $10^6$）。
統計答案：將最後第 N 行所有合法狀態的方案數相加，取模 10^6 後即為總方案數。
## 解題方法思考
狀態壓縮與範圍特性的結合：當看見 M <= 5 這樣極小的資料範圍時，第一直覺就應該想到狀態壓縮。
因為 3*2^(M-1) 的狀態數極少，完全可以把整行的組合壓成一個整數編號或向量來處理。
特殊行的處理策略：第 $K$ 行被固定的條件其實不需要把整張表格重構，只需要在 DP 進行到第 $K$ 行時，限制該行的轉移來源或目標只能是固定的那個狀態即可，這樣既直觀又不會破壞整體遞推結構。
## 複雜度分析
### 時間複雜度：
枚舉合法狀態：由於 M <= 5，總合法狀態數 T 大約為 48。狀態相容性矩陣預處理：需要檢查所有狀態對，複雜度為 O(T^2*M)。
DP 轉移過程：共有 N 行，每行需要遍歷狀態對進行轉移，複雜度為 O(N*T^2)。
總時間複雜度為 O(N*T^2 + T^2* M)，在 N <= 10^4、T <= 48 的情況下運算量極小，能輕鬆在幾毫秒內通過。
### 空間複雜度：
儲存所有狀態需要 O(T*M) 空間。狀態相容性矩陣需要 O(T^2) 空間。DP 陣列大小為 O(N*T)。
總空間複雜度約為 O(N*T + T^2)，記憶體消耗極低。
## 學習心得
這題讓我深刻體會到當題目資料範圍某個維度（如 M <= 5）極小時，使用「狀態壓縮」搭配「預處理轉移」是多麼強大的技巧。
原本看似複雜的網格約束問題，透過把「一整行」視為一個節點/狀態，就能轉化為類似圖論的轉移問題。
同時，學會了如何巧妙地在常規的 DP 過程裡插入特定行固定的約束條件，這對處理帶有特殊限制的序列動態規劃非常有幫助。
