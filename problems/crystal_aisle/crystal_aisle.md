# 晶體長廊的能源鋪設
## 題目意思
在星際遠征的基地中，工程師需要在長度為 2、寬度為 N 的矩形晶體長廊中鋪設防護磁磚。為了防禦宇宙射線，長廊必須被完全覆蓋且磁磚不能重疊。

目前基地提供了兩種規格的防護模組：

雙格直條型模組：大小為 2 個單位面積（可橫放或直放）。

L 型轉角模組：大小為 3 個單位面積（可任意旋轉）。

模組可以自由旋轉以適應空間，但長廊整體的長寬方向固定。工程師想知道，總共有多少種不同的鋪設方案可以完美覆蓋整個長廊？由於方案數量可能非常巨大，請將答案對 1000000007 取模後輸出。

## 輸入格式
輸入包含一個整數 N，表示晶體長廊的長度。

## 輸出格式
輸出一個整數，代表總鋪設方案數對 1000000007 取模後的結果。

## 範圍限制
N 的範圍為 1 到 10^7。
# 晶體長廊
## 題目想法
在觀察長廊鋪設的過程中，很快就會發現從第三個狀態開始，鋪設方式會出現對稱且重複的規律：
左邊一個 L 型、右邊一個倒過來的 L 型，中間則是兩列錯開放置的 I 型且能夠上下顛倒。
隨著長度 N 增加，組合方式會不斷擴展，因此需要透過動態規劃來系統性地找出所有可能的排列組合方式。
## 解題過程
定義狀態：定義動態規劃陣列 dp[i] 代表填滿長度為 i 的長廊的方法數。
狀態轉移：分析前幾項的組合，發現當前狀態 dp[i] 不僅與 dp[i-1]、dp[i-2] 有關，還會受到 L 型積木跨越所帶來的影響。
效能瓶頸：若直接針對每一項去用迴圈求和（sigma）計算，當 N 高達 10^7 時，整體計算量會變成 O(N^2)，導致程式逾時（TLE）崩潰。
## 解題方法
思考為了避免每次都重新進行迴圈求 sigma，利用一個累加變數 pre 來動態記錄並維護過去累積的項（例如 $2 \times dp[i-3]$ 的累加總和）。
這樣一來，就不需要每次都重複計算 sigma，而是透過前次累積的值直接加上去，將每次狀態轉移的時間複雜度壓到 O(1)。
## 複雜度分析
### 時間複雜度：O(N)。
只需要進行一次從 1 到 N 的線性迴圈，完美應對 N <= 10^7 的資料範圍。
### 空間複雜度：O(N)。
使用大小為 N+1 的 vector<ll> 儲存動態規劃狀態值（若有需要亦可進一步改用滾動陣列優化至 O(1)）。
## 學習心得
這題讓我深刻體會到，在面對大規模資料的動態規劃題目時，觀察圖形規律與狀態之間的相依性非常重要。
透過引入累加變數（pre）來取代重複的迴圈求和，是降低時間複雜度的經典技巧。學會這種最佳化方法後，面對 10^7 這樣的大規模測資也能夠輕鬆迎刃而解！
