# 星際探險
## 題目意思
你是一艘星際探測艦的艦長，正在一片 N x M 的網格狀星域中航行。這片星域具有特殊的折疊物理特性：如果你從星域的右邊界穿出，會直接從左邊界出現；從上邊界穿出，則會從下邊界出現（即為一個環面空間）。

現在探測艦位於起始座標 (X1, Y1)，由於能源系統受到干擾，你必須精準執行連續 K 次的「空間躍遷」來抵達指定的母艦救援座標 (X2, Y2)。對於第 i 次躍遷，系統已經鎖定了躍遷距離 d_i，但你可以自由決定本次躍遷的方向：向北（上）、向南（下）、向東（右）或向西（左）。

請你撰寫一個程式，判斷探測艦是否「有可能」透過這 K 次指定距離的躍遷，順利抵達母艦的所在位置。

## 輸入格式
輸入的第一行包含兩個整數 N 和 M，代表星域網格的大小。
第二行包含四個整數 X1, Y1, X2, Y2，分別代表探測艦的起始座標與目標座標。
第三行的第一個數字 K 為正整數，代表必須執行的躍遷次數，接下去有 K 個正整數 d_1, d_2, …, d_K，代表每次躍遷必須移動的距離。
同一行內的數字皆以一個空白間隔。

## 輸出格式
請判斷是否可能將探測艦移動至目標座標。若可以，請輸出 YES，否則輸出 NO。

## 範圍限制
1 <= N, M <= 100

1 <= K <= 10000

所有座標皆滿足 0 <= X < N 且 0 <= Y < M

1 <= d_i <= 100

# 星際探險
## 題目想法
本題的核心在於處理狀態在二維網格上的「上下左右位移」。由於每次移動都是針對盤面上的可行狀態進行擴散，且我們只在乎最後「能不能走到」目標點，因此可以將問題轉化為布林狀態的轉移與更新。

## 解題過程
一開始思考狀態轉移時，嘗試了幾種常規方法，但發現不管是哪種作法，時間複雜度似乎都會卡在 O(N * M * K)，在 K 最大到 10000 的情況下很容易遭遇效能瓶頸，一直不知道該怎麼把複雜度降下來。後來查閱了相關資料，才發現原來可以引入 bitset 來做常數級別的極致優化。

## 解題方法思考
這是一道標準的狀態位移題，而 bitset 的特性完美契合這個需求：它的左移 << 與右移 >> 運算子非常適合用來快速平移一整列的狀態；而位元或運算 | 更是適合用來合併、更新不同方向過來的狀態。結合滾動陣列將空間壓到最小，並透過取餘數處理環狀邊界，就能用極短的運算時間完成矩陣狀態的平移與覆寫。

## 複雜度分析
### 時間複雜度：
利用 bitset 將長度為 M 的列狀態壓縮，使得原本 O(N * M * K) 的時間複雜度大幅優化為 O(K * N * (M / 64))，順利通過測資限制。

### 空間複雜度：
利用 array<vector<bitset<100>>, 2> 實作滾動陣列，僅需保留當前與上一步的網格狀態，空間複雜度降至 O(N * (M / 64))。

## 學習心得
這次最大的收穫是見識到 bitset 在狀態壓縮與轉移上的威力。以後如果遇到這種「怎麼想都不知道怎麼把複雜度降下來」，且操作偏向「是/否」的矩陣狀態轉移時，就可以考慮使用 bitset。它在處理空間位移與狀態聯集上的優雅與高效，是非常實用的競程技巧！
