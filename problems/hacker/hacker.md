# 駭客
## 題目意思
在未來的賽博龐克世界中，你是一名潛入集團網路的頂級駭客，目前的初始位置在公共節點（座標 0）。沿著一維的資料主幹道上，分佈著 n 個藏有機密檔案的伺服器節點，它們的座標分別位於 1, 2, ..., n。

這 n 個伺服器節點有著各自獨立的防火牆重啟週期，第 i 個節點的防火牆只會在時間為 T[i] 的倍數時（即時間 0, T[i], 2T[i], 3T[i] ...）會產生瞬間的漏洞讓你下載檔案。

你的程式每在主幹道上移動 1 單位距離，需要花費 1 單位時間。當你抵達某個伺服器節點時，如果漏洞尚未出現，你必須停留在該節點隱蔽等待，直到下一次時間達到 T[i] 的倍數時才能成功下載。

請你規劃出一條最佳的潛入路線，計算出從座標 0 出發，下載完所有 n 個伺服器檔案所需的「最少總時間」。

## 輸入格式
第一行輸入一個正整數 n，代表伺服器節點的總數量。
第二行輸入 n 個正整數 T[1], T[2], ..., T[n]，數字之間以單一空白隔開，分別代表每個伺服器節點的防火牆重啟週期。

## 輸出格式
輸出一個整數，代表成功下載所有伺服器檔案的最少總時間。

## 範圍限制
1 <= n <= 18

1 <= T[i] <= 1000000000

# 駭客

## 題目想法
一開始沒有想到這題的最佳解法，主要原因在於忽略了 n 只有 16 這種異常小的資料限制。通常遇到這種小範圍的資料，就是一個極為強烈的暗示，代表這題需要使用平時較少用到的演算法：狀態壓縮 DP (Bitmask DP)。

## 解題過程
確定演算法後，利用 long long 的位元運算來將不同的走訪情況記錄成二進位狀態。透過逐步推演每個位元的變化，將所有的走訪路徑與週期等待時間的計算結合起來，確保程式能順利找出最短時間。

## 解題方法思考
動態規劃的狀態設計為 dp[mask][i]，這代表在走訪狀態為 mask 的情況下，且目前最後停留在位置 i 時，所需要花費的最少時間。
關於轉移方程式的設計，首先指定 mask 中已經走訪過的位置 i，接著枚舉尚未走訪過的位置 j。我們要處理的轉移邏輯，就是將目前的狀態 mask 加上位置 j，計算出移動並停留在位置 j 時所需的最小花費時間，以此來更新最佳解。

## 複雜度分析
* 時間複雜度：O(n^2 * 2^n)。
因為狀態總共有 2^n 種，而針對每一個狀態，都需要跑雙重迴圈去枚舉已走訪的位置 i 以及未走訪的位置 j。在 n 非常小的情況下，配合 -O3 編譯最佳化，能極快地運算完畢。

* 空間複雜度：O(n * 2^n)。
空間花費主要來自於儲存狀態的二維 vector 陣列，用來記錄 2^n 種走訪狀態對應 n 個可能停留位置的最短時間，記憶體用量完全在合理範圍內。

## 學習心得
這次最大的教訓是必須更敏銳地觀察題目的「資料範圍」，像這種 n 不超過 20 的條件，正是狀態壓縮 DP 的標準特徵。另外，在進行位元運算時統一使用 long long 型態，不僅能確保狀態涵蓋的範圍夠大，也能避免潛在的溢位錯誤。這是一個很棒的經驗，對於之後的 APCS 準備非常有幫助。
