# 雙人賽局
## 題目意思
有兩位尋寶者在一個古老的遺跡中發現了一排成列的寶箱，每個寶箱裡都有不同數量的金幣。為了公平起見，兩人決定輪流拿取寶箱，但每次只能選擇從這一排寶箱的「最左邊」或「最右邊」拿走一個。假設兩位尋寶者都非常聰明，且都會採取讓自己最終獲得最多金幣的最佳策略，請計算出先拿的尋寶者與後拿的尋寶者各自能獲得的總金幣數量。
## 輸入格式
第一行包含一個整數 N，代表寶箱的總數量。
第二行包含 N 個以空白分隔的整數，依序代表這排寶箱從左到右每個寶箱內的金幣數量。
## 輸出格式
輸出兩個整數，中間以一個空白隔開，分別代表先拿的尋寶者與後拿的尋寶者最終獲得的金幣總數。
## 範圍限制
1 <= N <= 1000
每個寶箱內的金幣數量介於 1 到 10000 之間。
# 雙人賽局
## 題目想法
起初對這道題完全沒有頭緒，不知道該如何同時處理兩個人輪流取物的最佳化策略。後來查閱資料後才恍然大悟，體會到了這類動態規劃解法的高明之處。這題最大的難點就在於有「兩個面向（先手與後手）」的交替，如果直觀地去記錄兩個人的分數，狀態會變得非常複雜。
## 解題過程
解這題最巧妙的突破口在於，DP 陣列裡記錄的不是某個人的絕對總分，而是記錄「一段區間內，當前玩家與對手的得分差」。剛開始可能會覺得這只是一個區間分數差，但透過數學原理的正負號轉換，竟然就能夠完美處理雙方互相牽制的賽局問題，只需要解出最終的得分差，就能利用總和反推出兩人的實際得分。
## 解題方法思考
狀態定義 dp[i][j] 為在區間 [i, j] 中，先拿的人能比後拿的人多出多少分。
假設我們面臨區間 [i, j]，我們有兩種選擇：
 * 試著拿左邊的 A[i]：剩下的區間 [i+1, j] 會交給對手。對手在剩下區間的最大得分差為 dp[i+1][j] (即 B - A)。換算回我們的視角，我們的得分差就會是 A[i] 減去對手的得分差，也就是 A[i] - (B - A) = A - B + A[i]，這正好等價於 A[i] - dp[i+1][j]。
 * 試著拿右邊的 A[j]：同理，剩下的區間交給對手，狀態會變成 A[j] - dp[i][j-1]。
因為雙方都是極度聰明的，所以我們會在這兩個選擇中取最大值：dp[i][j] = max(A[i] - dp[i+1][j], A[j] - dp[i][j-1])。
最後，算出整個區間 [1, n] 的最大得分差 dp[1][n] 後，利用聯立方程式：
A + B = SUM
A - B = dp[1][n]
即可解出先手 A 的總分為 (SUM + dp[1][n]) / 2，後手 B 則為 SUM - A。
## 複雜度分析
### 時間複雜度：O(N^2)。
需要窮舉所有可能的區間長度 len (從 2 到 N)，以及每個區間的起點 i，總共大約需要計算 N^2 個狀態。
### 空間複雜度：O(N^2)。
建立了一個 N * N 的二維陣列 dp[i][j] 來儲存各個區間的狀態轉移結果。
## 學習心得
這題讓我見識到了利用「相對差值」來轉換視角的數學思維。原本以為需要紀錄雙方的絕對分數才能模擬整個過程，但透過正負號的顛倒與相減，完美的將對手的最佳策略反轉融合進自己的狀態轉移中。這不僅讓程式碼變得非常乾淨，也對於未來處理賽局理論與區間 DP 問題提供了一個非常棒的思考維度。
