# 禮盒切割術
## 題目意思
在台北迪化街經營數十年的「春發記」傳統糕餅舖最近接到了一筆大訂單。店裡招牌的招牌長方形大喜餅，長度為 m 公分、寬度為 n 公分。為了滿足不同客人的送禮需求，師傅需要對大喜餅進行精準的切割與包裝規劃。

喜餅切割規則如下：

刀工切割：師傅可以對喜餅進行垂直或水平的刀工切割。如果是第一次切割，必須從喜餅的一邊完全切到另一邊；如果是後續的切割，則限定只能在某一個已切割好的塊狀區域內進行，且同樣要從該區塊的一邊切到對應的另一邊。

無限切割：切割次數不限，可以依據訂單需求進行多層次分割。

禮盒配置：在最後切割出來的每一塊獨立喜餅區域中，可以放入一個尺寸不大於該區域的精美獨立包裝禮盒。
4.餅舖目前提供 k 款不同尺寸的現成禮盒。對於第 i 款禮盒，其長度為 h_i 公分、寬度為 w_i 公分，對應的販售利潤為 p_i 元。在包裝時，禮盒可以視實際需要旋轉 90 度後再裝入，並不會影響其販售利潤。

請幫老店掌櫃設計一個最佳的切割與禮盒配置方案，使得在這個 m 乘以 n 平方公分的巨大喜餅中，所能獲得的總利潤達到最大化。請注意，由於現有禮盒尺寸和刀工限制，可能無法完全用禮盒填滿整個喜餅區域，且有時刻意保留一些邊角碎料反而能讓整體利潤達到最高。

## 輸入格式
輸入資料的第一列包含三個正整數，依序為屋頂的長度 m、寬度 n，以及禮盒的款式數量 k。
在接下來的 k 行中，每一行包含三個正整數，分別代表第 i 款禮盒的長度 h_i、寬度 w_i 以及利潤 p_i。
其中限制條件為：

0 < h_i, w_i <= max(m, n)

0 < p_i <= 100

## 輸出格式
請輸出一個整數，代表所有包裝方案中所能達到的最大總利潤。

## 範圍限制
第一子題組 [10 分]：m < 10, n < 10, k = 1 且 h_1 = w_1

第二子題組 [12 分]：m < 10, n < 10, k = 1 且 h_1 != w_1

# 禮盒切割術
## 題目想法
這是一道典型的二維矩形切割最佳化問題。面對一個 m <= n 的大喜餅，我們需要在允許無限次水平或垂直切割的規則下，找出能放入各種現成禮盒（且可旋轉 90 度）的最高總利潤組合。
因為切割點的位置和組合非常多，無法用單純的貪婪法解決，必須透過動態規劃來系統性地枚舉所有可能的切割方式與直接放置方案。
## 解題過程
輸入與初始化：讀取屋頂長度 m、寬度 n 以及禮盒款式數 k，並配置大小合適的二維向量 dp 與 best（多預留空間避免邊界溢出）。建構基礎價值陣列 (best)：遍歷所有給定的禮盒。
考量到禮盒可以旋轉，將尺寸 (h, w) 與 (w, h) 分別對應到 best[h][w] 與 best[w][h]，記錄能放入的最高利潤 p。
二維前綴最大值擴展：利用雙重迴圈將 best[i][j] 向上與向左擴展（max(best[i-1][j], best[i][j-1])），確保任意尺寸的單一未切割區塊都能直接查表得到最佳的現成禮盒利潤。
二維區間切割 DP 轉移：區分從小到大的矩形尺寸 i*j。對每個尺寸，先預設不切割的價值為 best[i][j]。
枚舉所有可能的水平切割線 s（高度切成 s 與 i-s），狀態轉移為 dp[s][j] + dp[i-s][j]。枚舉所有可能的垂直切割線 p（寬度切成 p 與 j-p），狀態轉移為 dp[i][p] + dp[i][j-p]。
輸出結果：最終輸出 dp[m][n] 即為該 m <= n 區域所能產生的最大總利潤。
## 解題方法思考]
這是第一次接觸二維的前綴觀念與二維切割處理的 DP。與一維的區間 DP（如矩陣連乘）類似，二維切割的核心精神在於將一個大矩形「切成兩半」，讓大問題拆解成兩個獨立子問題的組合。
不切的時候：依賴 best 陣列與二維前綴最大值，直接對應大區塊塞入單一禮盒的極值。要切的時候：透過內層迴圈窮舉所有可能的切割位置（橫切或豎切），將兩側子區域的 DP 值相加取最大值。
這種由小尺寸矩形推導到大尺寸矩形的過程，完美解決了子問題重疊的問題。
## 複雜度分析
### 時間複雜度：O(mn(m + n) + k)。
外層雙重迴圈枚舉矩形長寬 $m$ 與 $n$（共 m <= n 種狀態），內層迴圈則分別枚舉高度切割點 s（約 m 種）與寬度切割點 p（約 n 種），在 m, n <= 500 的限制下能夠在時限內高效執行。
### 空間複雜度：$O(mn)$。
使用了兩個大小為 (m+5)*(n+5) 的二維向量來儲存 dp 與 best 狀態，記憶體開銷非常小。
