# 能量防護網
## 題目意思
在古老的魔法王國中，有 N 個水晶塔透過 N-1 條能量光纖互相連結，形成一棵樹狀的網狀結構。為了抵禦即將到來的暗影入侵，守護者必須在部分水晶塔上啟動防護結界。
為了確保防禦網的完整性，每一條能量光纖的兩端至少必須有一個水晶塔啟動了防護結界。在第 i 個水晶塔上啟動結界需要花費 a_i 點魔力值。
請協助守護者計算出，要讓所有能量光纖的兩端都至少有一個結界保護，所需的最小總魔力消耗為多少？
## 輸入格式
第一行有一個整數 N，代表水晶塔的總數量。接下來有 N-1 行，每行有兩個整數 u 和 v，表示編號 u 與編號 v 的水晶塔之間有一條能量光纖相連（節點編號從 0 到 N-1）。
最後一行有 N 個整數，第 i 個整數代表在第 i 個水晶塔啟動結界所需的魔力值 a_i。
## 輸出格式
輸出一個整數，代表保護所有能量光纖所需的最小總魔力消耗。
## 範圍限制
節點數量 N 的範圍為 1 到 2*10^5 之間。每個節點的魔力值 a_i 為非負整數。輸入資料保證會構成一棵樹。

# 能量防護網
## 題目想法
這是我剛開始接觸樹形 DP 時所遇到的題目，只不過當時沒有解出來。而現在回頭再看，發現它其實是最基礎的樹形 DP，因為每個節點的狀態非常單純，只有兩種可能：
它是黑的（選取）或它不是黑的（不選取）。透過這種清晰的二元狀態定義，我們能在整棵樹上進行狀態轉移。
## 解題過程
使用深度優先搜尋（DFS）從根節點出發，遞迴遍歷整棵樹直到葉節點，並在回溯過程中更新狀態。對於每個節點，我們維護兩個狀態：當前節點不選（0）：
其所有子節點都必須被選擇。當前節點選擇（1）：其子節點可以選擇也可以不選擇，取決於哪種狀態的成本較低。
最後透過遞迴返回根節點的最小總成本。解題方法思考樹形 DP 的核心思維與一般 DP 類似，都是利用子問題的解來組合出當前問題的解。
然而其獨特之處在於它是以「該節點往下的子樹已知結果」為基礎，再針對該節點的不同狀態去做處理。
在樹狀結構中，透過 DFS 的後序遍歷順序，確保在處理父節點時，所有子樹的 DP 狀態都已經計算完畢。
## 複雜度分析
### 時間複雜度：O(N)。
每個節點與每條邊在 DFS 過程中僅被走訪與轉移常數次，能高效處理至 2*10^5 的測資規模。
### 空間複雜度：O(N)。
用於儲存樹的鄰接串列以及記錄各節點狀態的 DP 表格，記憶體開銷與節點數呈線性成長。

回想當初剛接觸樹形 DP 時覺得很抽象，甚至這題在當時還沒能解出來。但現在重新審視，才發現它是最經典的入門款：
因為節點狀態只有黑與白兩種，透過簡單的遞迴與狀態轉移就能完美破解。這讓我深刻體會到演習與累積的重要性，過去卡關的題目，現在已經能用清晰的架構與高效的程式碼穩穩拿下了。
