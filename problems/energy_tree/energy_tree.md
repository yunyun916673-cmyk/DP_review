# 能量樹
## 題目意思
在古代的艾爾利亞王國中，生長著一棵巨大的遠古水晶魔樹。這棵魔樹由 N 個節點組成，節點編號為 0 至 N-1，並由 N-1 條魔法能量脈絡相連，確保任意兩個水晶節點之間都恰好存在一條唯一的能量流通路徑（形成一棵樹狀結構）。

每個水晶節點內部都蘊含著特定屬性的能量數值，該數值可能為正數（代表純淨的增益能量）、零或負數（代表受污染的反噬能量）。魔法學徒需要挑選出一個非空的「連通水晶子圖」（即選出的節點集合必須互相連通，形成一棵連通子樹），使得選取的所有水晶節點能量總和達到最大。

請撰寫一個程式，計算該魔樹中任意連通子樹所能產生的最大能量總和。

## 輸入格式
第一行包含一個正整數 N，代表魔樹的節點總數。

接下來的 N-1 行，每行包含兩個整數 u 與 v，代表編號為 u 與編號為 v 的水晶節點之間存在一條相連的魔法脈絡。

最後一行包含 N 個整數，依序代表編號 0 至 N-1 各節點的水晶能量數值。

## 輸出格式
輸出一個整數，代表所能選取的非空連通子樹之最大能量總和。

## 範圍限制
1 <= N <= 100000

0 <= u, v < N，保證輸入構成一棵樹

# 能量樹
## 題目想法
給定一棵具有點權的樹，點權有正有負，目標是找出一棵連通子樹使其所有點的權重和最大。由於要求所選節點必須互相連通，因此對於任意節點，若要將某個子節點的子樹納入答案中，該子樹必須與當前節點相連。這意味著在樹狀結構由下而上回傳時，針對每一個子樹有兩種選擇：若子樹貢獻為正，則選擇保留該子樹以增加總權重；若子樹貢獻為負，則選擇切斷與該子樹的連線，不納入累加。

## 解題過程
構建無向樹：讀取 N 個節點與 N-1 條邊，以鄰接表儲存雙向邊，並讀取各節點的權重。

定義遞迴狀態：定義函式 dfs(u, p)，其回傳值代表以節點 u 為根且必須包含節點 u 本身的子樹中所能形成的最大連通塊權重和。

子樹選擇與合併：

遍歷節點 u 的所有子節點 v（忽略父節點 p）。

對每個子節點遞迴計算其最優值 dfs(v, u)。

判斷子樹貢獻：若 dfs(v, u) > 0 則保留並累加至當前節點的總和；若 dfs(v, u) <= 0 則切斷不取，等價於累加 max(0LL, dfs(v, u))。

維護全域最優解：當前節點 u 合併完所有子樹的正貢獻後，該值即代表以 u 為最高節點所能擴展出的最佳連通塊。每次計算完畢皆以該值更新全域最大值 ans。

回傳向上傳遞：回傳當前節點計算出的最佳和，供父節點做是否保留的決策。

## 解題方法思考
本題的核心機制在於「連通性限制」與「子樹截斷策略」的結合：

強制包含根節點以滿足連通性：若 DP 狀態不強制包含當前根節點，父節點便無法判斷子節點回傳的連通塊是否能與自己相接。因此將狀態限制為「必須包含當前節點」，才能將結構正確地由葉節點向根節點自底向上延伸。

正負貢獻的決策：在樹形 DP 中，子問題彼此相互獨立。當子節點所能提供的最大連通塊和小於或等於零時，將其連線切斷對當前節點最為有利；只有在子樹權重總和為正時，保留並接合該子樹才能使當前節點的權重增大。

全域極值的產生位置：最優的連通塊不一定必須延伸到整棵樹的預設根節點（節點 0），它可能孤立在樹中的任何一個分支上。透過在每個節點遞迴結束時更新全域變數 ans，能不遺漏地覆蓋所有以任意節點為最高點的最佳連通塊。

## 複雜度分析
### 時間複雜度：O(N)。
整棵樹採用一次深度優先搜尋（DFS），每個節點與每條邊皆被拜訪常數次，節點內的轉移僅需遍歷子節點並取 max，計算量極低。

### 空間複雜度：O(N)。
鄰接表儲存樹的邊結構佔用 O(N) 空間，遞迴呼叫堆疊在最壞情況（樹退化為鏈狀）下深度為 O(N)。

## 學習心得
樹形動態規劃的精髓在於釐清「子狀態的定義」與「回傳值的連通性保證」。在面對允許選擇局部連通圖的題目時，將 DP 狀態定義為「強制包含根節點」能讓狀態轉移保持高度簡潔。在自底向上的合併過程中，直接使用 max(0LL, sub_tree_val) 即可優雅地表達「切斷負權子樹、保留正權子樹」的貪心決策，避免了複雜的狀態分支討論。

每個節點的能量數值介於 -1000000000 至 1000000000 之間
