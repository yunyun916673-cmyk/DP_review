# 歷史檔案
## 題目意思
國家歷史檔案館最近在整理一批珍貴的歷史檔案文獻。這批文獻共有 n 份，依序編號排列，每份文獻都對應到一個特定的主題分類代號（以整數表示）。
為了進行專題研究，學者需要從這排文獻中挑選出一段「連續的區間」，且這段連續區間內的文獻主題代號絕對不能有任何重複，否則研究主題會互相衝突。
請你寫一個程式，協助學者找出所有符合「主題完全不重複」的連續區間中，長度最長的那一段。如果有多個最長區間，請輸出最左邊（起始位置最小）的那一個區間之起始位置與長度。
## 輸入格式
第一行包含兩個整數 m 與 n，分別代表主題代號的最大可能範圍以及文獻的總數量。
第二行包含 n 個整數，依序代表第 1 到第 n 份文獻的主題分類代號。
## 輸出格式
輸出兩個整數，分別代表符合條件的最長不重複區間之起始位置與區間長度。
## 範圍限制
1 <= m,n <= 500,000

# 歷史檔案
## 題目想法
本題要求在給定的數列中，尋找一段「元素完全不重複」的最長連續子區間（即滑動視窗／雙指標概念），並輸出該區間的起始位置與最大長度。若有多組相同最大長度的區間，則取起始位置最靠左的那一組。
## 解題過程
建立三個長度足夠的 vector 陣列：line 儲存輸入的 n 個主題分類代號（採用 1-based 索引以方便計算區間位置）。last_pos 記錄每個代號在目前位置之前「最後一次出現的索引」，初始值皆設為 0。
L 記錄以第 i 個位置作為結尾時，合法不重複區間的最左邊界索引。依序掃描 i = 1 到 $n$：若當前數字 line[i] 曾經出現過，則新的左邊界必須至少在 last_pos[line[i]] + 1 之後，才能避開重複元素。
同時也必須受限於前一個位置的左邊界 L[i-1]。因此狀態轉移式為：L[i] = max(L[i-1], last_pos[line[i]] + 1)。
更新當前數字的最後出現位置：last_pos[line[i]] = i。再次遍歷所有位置 i = 1 到 n，計算以 i 結尾的最長合法區間長度 cnt = i - L[i] + 1。
透過嚴格大於條件（cnt > ans）更新最大長度與起始位置 s = L[i]，確保長度相同時保留最左邊的解。
## 解題方法思考
這題的核心概念其實和經典題「美食博覽會」的上半部非常相似，本質上就是利用一維動態規劃（DP）的狀態轉移思維來維護合法區間的左邊界。
在思考如何避免重複元素時，如果對每個結尾都重新往回暴力比對，時間複雜度會退化為 $O(N^2)$。透過記錄每個數字「上一次出現的位置（last_pos）」，我們就能把問題轉化為遞推關係：
以位置 $i$ 結尾的最長不重複區間左端點，必然不會超過前一個狀態的左端點 L[i-1]，也不會包含 line[i] 上一次出現的位置。
這種結合雜湊陣列記錄狀態與線性 DP 維護邊界的做法，能以極低的常數在單次掃描內求得所有結尾的最優解。
## 複雜度分析
### 時間複雜度：O(N)。
讀取輸入、線性掃描維護左邊界 L[i]，以及最後尋找最大區間長度的三個迴圈皆為線性時間，總時間複雜度為 O(N) 能輕鬆通過大數據測試。
### 空間複雜度：O(N + M)。
使用了 line 與 L 兩個大小為 N+1 的陣列，以及一個大小為 M+1 的 last_pos 陣列來記錄數值最後出現的索引。
## 學習心得
這題讓我再次體會到將「雙指標／滑動視窗」轉化為「動態規劃狀態轉移」的簡潔性。
直接利用 L[i] = max(L[i-1], last_pos[line[i]] + 1) 來維護區間左界，不僅省去了內層 while 迴圈逐步移動左指標的繁瑣操作，也讓程式邏輯變得非常直觀。
此外，由於題目要求輸出「起始位置」與「長度」，在記錄答案時使用 1-based 索引並搭配嚴格大於（cnt > ans）的判斷條件，
就能自然滿足「長度相同時取最左邊區間」的題意要求，是一個非常實用的技巧。
