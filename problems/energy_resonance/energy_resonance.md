# 能量共鳴
## 題目意思
王國的魔法防禦體系由 N 座浮空能量塔組成，塔與塔之間由特殊的魔力共振通道相連，剛好形成一個無向無環的樹狀網路。每座塔自身蘊含著特定數值的魔力核心，如果啟動該塔，就能釋放出對應的防禦能量。

然而，古老的防護法則限制：如果兩座能量塔之間存在直接相連的通道，它們便無法同時被啟動，否則會因為魔力流過度集中而產生短路自爆。

身為王國的首席陣法師，你的任務是從這 N 座能量塔中選擇啟動若干座塔，在絕不讓任何直接相連的兩座塔同時啟動的前提下，使所獲得的防禦總能量最大化。

## 輸入格式
第一行包含一個整數 N，代表能量塔的總數（塔編號由 0 至 N - 1）。

接下來的 N - 1 行，每行包含兩個整數 u 與 v，表示編號為 u 與編號為 v 的能量塔之間有一條直接通道。

最後一行包含 N 個整數，第 i 個整數代表編號為 i 的能量塔在啟動時能提供的能量數值。

## 輸出格式
輸出一個整數，代表在滿足安全條件下能獲得的最大總能量。

## 範圍限制
1 <= N <= 6000

0 <= u, v < N，保證所有通道連成一棵樹

能量數值在 -128 到 127 之間（或更常見的 0 到 10^5，本題資料保證總和在 64 位元整數可表示範圍內）

# 能量共鳴
## 題目想法

本題屬於經典的樹狀動態規劃（Tree DP）入門題，等價於在樹狀圖上求解「最大權獨立集」（Maximum Weight Independent Set）。核心限制在於：
相鄰節點（存在直接父子關係）不可同時選取。因此，對於樹上的每個節點，其決策狀態本質上只有兩種：選（1） 或 不選（0）。
整棵樹的最佳解可以透過子樹最佳狀態的由下而上彙整逐步推導出來。
## 解題過程
資料結構定義：以鄰接表儲存無向樹的邊關係，並使用動態規劃陣列 dp[u][0] 與 dp[u][1] 分別記錄以節點 u 為根的子樹中，在「不選節點 u」與「選取節點 u」兩種情況下所能獲得的最大權重和。
初始化與基礎狀態：當不選節點 u 時，基礎價值為 0。當選取節點 u 時，基礎價值為該節點本身的權重 A[u]。DFS 遍歷與狀態轉移：
任選一個節點（如節點 0）作為樹根發動深度優先搜尋（DFS），並傳入父節點指標避免回溯走訪。先遞迴走訪所有子節點 nxt，等子樹各狀態計算完成後再進行狀態合併：
若當前節點 u 不選，其子節點 nxt 處於自由狀態，可選也可不選，因此累加 max(dp[nxt][0], dp[nxt][1])。
若當前節點 u 選取，依題目規則其所有直接子節點 nxt 嚴格受限為不可選，因此只能累加 dp[nxt][0]。
輸出結果：整棵樹計算完畢後，取根節點兩種狀態的最大值 max(dp[0][0], dp[0][1]) 即為全域最佳解。
## 解題方法思考
樹狀 DP 最具代表性的思維在於利用樹結構天然的遞迴性質進行「後序遍歷（Post-order Traversal）」。
每一層的狀態維度很小（僅 2 種布林狀態），但透過由葉節點向根節點的聚集轉移，成功將一個全域組合爆炸的子集選取問題，化簡為局部約束明確的線性多項式時間問題。
即使原圖給定為無向樹，只要在 DFS 過程中記錄來向父節點 pnt，即可視為有根樹處理，不需要顯式拓撲排序或額外找出入度為 0 的根節點。
## 複雜度分析
### 時間複雜度：O(N)。
每條邊與每個節點在 DFS 過程中僅被訪問常數次，狀態轉移為 O(1)，在 N <= 6000 的規模下可在數毫秒內高效通過。
### 空間複雜度：O(N)。
主要消耗在儲存樹邊結構的鄰接表、dp 陣列以及遞迴呼叫堆疊（最差退化為鏈狀樹時遞迴深度為 O(N)）。
## 學習心得
這題作為樹形 DP 的基石題目，清楚展現了「二元狀態約束」在樹狀拓撲上的優雅遞迴模式。對於某一節點而言，選與不選的狀態劃分直接決定了子節點能轉移的邊界。
掌握這種由葉至根合併狀態的範式後，未來面對節點覆蓋、樹上背包、或是換根 DP（Rerooting DP）等更複雜的樹上模型時，都能以相同的子樹狀態劃分邏輯作為核心出發點。
