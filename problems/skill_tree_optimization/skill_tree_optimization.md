# 技能樹優化
## 題目意思
在宇宙學術聯盟中，有 N 門前瞻科研課程（編號從 0 到 N-1）。每門課程之間存在先修依賴關係，形成一棵以 0 號課程為根的樹狀結構。修習某門課程可以獲得對應的學分。
現在學員最多可以選擇修習 M 門課程。請計算在符合先修依賴關係的前提下（即若選擇某門課程，其先修路徑上的課程必須被包含在選取的課程中），最多可以獲得多少總學分。
## 輸入格式
第一行包含兩個整數 N 和 M，分別代表課程總數與允許選修的最大課程數。接下來 N-1 行，每行包含兩個整數 u 和 v，表示課程 u 與課程 v 之間存在一條直接的依賴邊。
最後一行包含 N 個整數，第 i 個整數代表修習第 i 門課程可獲得的學分。
## 輸出格式
輸出一個整數，代表在限制條件下所能獲得的最大總學分。
## 範圍限制
1 <= N <= 3000  0 <= M <= N  0 <= A[i] <= 1000

# 技能樹優化
## 題目想法
這是一道經典的樹上背包問題（Tree DP Knapsack）。由於每門課程都有先修課程的限制，這些依賴關係會形成一棵樹。
因此我們可以使用深度優先搜尋（DFS）來遍歷整棵樹，並在回溯的過程中，將子樹的學分狀態合併到父節點上，以此計算出在限定選修總數 M 的情況下所能獲得的最大學分。
## 解題過程
建立鄰接表與初始化：使用無向圖的鄰接表 ship 儲存課程先修關係，並以傳入父節點 pnt 的方式避免在樹上重複訪問。
狀態定義：設 dp[pwd][j] 代表以 pwd 為根的子樹中，總共分配了 j 個課程名額（包含 pwd 本身）時所能獲得的最大學分。
邊界與初始化細節：為了避免非法狀態干擾，將 dp 陣列初始化為極小值（如 LLONG_MIN / 4LL）。在進入節點 pwd 時，必須特別注意初始化：
不分配任何名額的學分為 dp[pwd][0LL] = 0，而只分配給自己 1 個名額的學分為 dp[pwd][1LL] = A[pwd]。解題方法思考在處理樹上背包時，若直接進行子樹合併，其時間複雜度容易劣化。
透過 DFS 結合背包體積的倒序枚舉（類似 0/1 背包），我們可以確保每個子樹的節點只會在所屬子樹的大小範圍內進行狀態轉移。
轉移方程式為：  dp[pwd][j] = max(dp[pwd][j], dp[pwd][j-k] + dp[nxt][k])
其中 j 代表當前分配給目前子樹的總名額，k 代表分配給子樹 nxt 的名額。透過兩層迴圈枚舉體積與子樹分配，能有效在規定時間內算出最佳解。
## 複雜度分析
### 時間複雜度：
樹上背包的時間複雜度為 O(N*M)，其中 N 為課程總數，M 為最大選修數。在本題規模下可以高效執行完畢。
### 空間複雜度：
O(N*M)，用於儲存每個節點對應不同名額限制下的 DP 狀態表。
## 學習心得
這次練習讓我更熟練掌握了樹上背包（Tree DP）的轉移模板。
特別體會到在初始化階段，必須嚴格設定 dp[pwd][0LL] = 0 與 dp[pwd][1LL] = A[pwd] 的重要性，否則在狀態合併與無效狀態的傳遞上容易出現錯誤。
這對於後續應對更複雜的樹狀動態規劃題目打下了非常穩固的基礎。
