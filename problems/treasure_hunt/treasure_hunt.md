# 遺跡尋寶
## 題目意思
你是一位冒險者，來到了一處古老的遺跡尋寶。你身上帶了一個背包，背包的重量上限為 T。
在遺跡中，你發現了 n 種稀有的古文物。對於每一種文物，你都能清楚知道它的重量、可以賣出的價值，以及該種類文物的總數量。
為了在不超過背包重量上限的前提下，帶走最高總價值的文物，請你計算出最大能獲得的價值是多少。

## 輸入格式
第一行有一個整數 n，代表古文物的種類數量。
接下來有 n 行，每行有三個以空白隔開的整數 w, v, c，分別代表該種文物的「重量」、「價值」與「數量」。
最後一行有一個整數 T，代表背包的重量上限。

## 輸出格式
請輸出一個整數，代表能帶走的最大總價值。

## 範圍限制
1 <= n <= 50
1 <= w, v, c <= 100
1 <= T <= 10000

# 遺跡尋寶
## 題目想法
這題的核心就是標準的「有限背包」（也就是多重背包）問題。它的性質介於「完全背包」（物品數量無限）與「0/1 背包」（單調背包，物品數量僅限一個）之間，最大的特徵在於每種物品都有明確的「數量限制」，因此在處理 DP 狀態時，必須針對數量的上限進行額外的控制。

## 解題過程
首先宣告一個結構體 dat 來整齊儲存每種物品的重量 (W)、價值 (V) 與數量 (C)。接著建立一個大小為 (n+1) x (t+1) 的二維陣列 dp，並將初始值設為 0。
程式主體透過三層迴圈來處理：外兩層負責遍歷所有的物品種類 (i) 與當前的背包容量 (j)，最內層則負責枚舉當前物品實際拿取的數量 (k)。枚舉時需嚴格遵守兩個條件：一是拿取數量不能超過該物品的總數 C，二是拿取後的總重量不能超過當前背包容量 j。

## 解題方法思考
狀態轉移方程式的思考相當直觀，建立在 0/1 背包的基礎上加上數量的維度。對於第 i 種物品，我們嘗試拿取 k 個。
轉移式為：dp[i][j] = max(dp[i][j], dp[i-1][j - k * W] + k * V)
為了確保程式碼在極端測資下不會發生溢位，所有變數、迴圈計數器以及常數後綴，我都習慣採用 long long (ll) 以及 0LL、1LL 的嚴謹型態標示，這能大幅提升解題時的穩定度。

## 複雜度分析
### 時間複雜度：
O(N * T * C)，其中 N 為物品種類數量，T 為背包總容量，C 為單一物品的最大數量限制。此題測資範圍最大約為 50 * 10000 * 100，三層迴圈的計算量在合理範圍內，可順利 AC。

### 空間複雜度：
O(N * T)，使用二維 DP 陣列紀錄所有狀態。若後續遇到記憶體限制更嚴格的題目，可考慮使用一維滾動陣列的技巧將其壓縮至 O(T)。

## 學習心得
透過這題，清楚釐清了有限背包與完全背包、單調背包之間的差異與過渡關係。這類有數量限制的 DP，雖然只是在原有的背包邏輯上多加上一層枚舉的迴圈，但卻是動態規劃中非常基礎且重要的一環，不僅穩固了基礎的 DP 狀態轉移觀念，也為接下來 APCS 更複雜的狀態壓縮與優化打下好的基礎。
